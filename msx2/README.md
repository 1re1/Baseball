# MSX STADIUM（MSX2 用 野球ゲーム）

ファミコンの『プロ野球ファミリースタジアム』の遊び心地をまねて作った、MSX2 用の野球ゲームです。
絵・曲・チーム名・選手名はすべて自作で、ナムコの素材は使っていません（ファンメイドの作品です）。

- ファイル：`MSXSTADIUM.ROM`（512KB = 4M ビット、メガROM **ASCII16**。ASCII8 として読み込まれても起動時に判定して動きます）
- 保存：**フロッピーディスクドライブ**のある機種では、ディスクの `MSXSTAD.DAT`（1536 バイト）に、EDIT したチームとトーナメントの途中経過を保存します。
  ドライブがなくても試合・トーナメントは遊べます（EDIT と保存・続きからだけが使えません）。カートリッジの SRAM には対応していません
- 動く機種：MSX2 / MSX2+ / turbo R（RAM 64KB 以上）。MSX1 では「MSX2 専用」と表示して止まります
- 確認した環境：openMSX（C-BIOS MSX2、Panasonic FS-A1 / FS-A1GT、Sony HB-F1XD / HB-F1XV、Philips NMS 8245）、WebMSX 6.0

## 動かし方

- **openMSX**：`openmsx -machine Panasonic_FS-A1 -cart MSXSTADIUM.ROM`（自動で ASCII16 と判定されます）。
  保存するときは、ディスクドライブのある機種で `openmsx -machine Sony_HB-F1XD -cart MSXSTADIUM.ROM -diska フォルダ名`
  （フォルダか .dsk ファイルがディスクになり、`MSXSTAD.DAT` が書かれます）
- **WebMSX**：ROM を読み込むだけ（WebMSX は ASCII8 と判定しますが、そのまま動きます）。
  WebMSX の初期設定はドライブ A にディスクが入っていないので、保存するときは先に画面下のディスクのアイコン（Drive A）から
  空のディスクを入れてください（「Add Blank Disk」など。入れずに保存すると「ディスク ニ セーブ デキマセン」と出ます。後から入れれば保存できます）
- **blueMSX**：ROM を読み込むだけ。うまく動かないときはマッパーを「ASCII16」にしてください
- **実機**：メガROM が使えるカートリッジ（Carnivore2、MegaFlashROM など）に ASCII16 として書き込みます

**フロッピーディスク**：ディスクドライブのある機種（HB-F1XD、NMS 8245、FS-A1GT など。外付けドライブも）では、起動時にディスクの
`MSXSTAD.DAT` を読み、EDIT の保存（START）とトーナメントの保存のたびにディスクへ書きます（1〜2 秒、その間は音が止まります）。
ファイルがなければ ROM のチームから始まります。ディスクが入っていない・書き込み禁止のときは「ディスク ニ セーブ デキマセン」と出て、
そのまま続けられます（その回の変更は電源を切るまで残ります）。openMSX では `-diska フォルダ名` でフォルダをディスクとして使えます。

## 遊び方

タイトル画面で ↑↓ で行を選び、モード（● が選んだモード。6 種類）、`イニング`（←→ で 3・6・9）、`SPEED`（←→ で 1〜5）を決めてスペース。
`SPEED` は試合ぜんたいの動きの速さです（1 = 60%・2 = 70%・3 = 80%（ふつう）・4 = 90%・5 = 100%）。投球・打球・送球・走者・守備がすべて同じ割合で速く／遅くなります。
チームを選ぶと両チームのスターティングオーダーが出ます（スペースで試合開始）。
タイトルで 10 秒何もしないと COM 同士のデモ試合が始まります（スペースで戻ります）。

| モード | 内容 |
|---|---|
| 1P VS COM | 1P が先攻、COM が後攻（チームはどちらも 1P が選びます） |
| 1P VS 2P | 1P が先攻、2P が後攻 |
| COM VS COM | 観戦 |
| EDIT | チーム・選手を書きかえてフロッピーディスクに保存（→「EDIT モード」） |
| TOURNAMENT | 6 チームのトーナメント（→「トーナメント」） |
| CONTINUE | 保存したトーナメントの続きから |

### 守り（投手）

- ←→：プレートの位置をずらす
- **B ＋ 塁の方向で牽制球**（投手から見て →一塁 ↑二塁 ←三塁）。走者のいない塁の方向では何もしません。
  走者が 1 人もいないときは、B でも投球します（方向なしの B も投球）。COM の投手も、一塁の足の速い走者にときどき牽制します。
  牽制で戻るのが遅れた走者（ふつうはすぐ戻ります。ときどき逆を突かれます）は、ベースに入った守備のタッチでアウト
- A：投げる。**↓ を押しながら = 速球**（その投手の最高球速）、何も押さない = 普通（最高 − 8km、最低球速より遅くはならない）、
  **↑ を押しながら = 遅い球**（その投手の最低球速）。振りかぶっている間に押しても効きます
- 140km 以上の速球は、見た目もひと回り速く飛び、「ひゅん！」と高い音が鳴ります
- **球種のコマンド**：投げる前に同じ方向を 2 回すばやく押して（約 0.27 秒以内）、0.7 秒以内に A
  | コマンド | 球種 | 動き |
  |---|---|---|
  | ↓↓ ＋ A | フォーク | まっすぐ来て、打者の手前でストンと落ちる（球速 −8km。当てにくく、ゴロになりやすい） |
  | ←← か →→ ＋ A | カーブ | 投手の利き腕と反対へ（右投手なら →→ で一塁側へ）。浮き上がってから落ちる山なりで、だんだん大きく曲がる（7〜15 ドット、球速 −16km） |
  | ←← か →→ ＋ A | シュート | 投手の利き腕の側へ（右投手なら ←← で三塁側へ）。手元で鋭く曲がる（4〜8 ドット、球速 −5km） |
  曲がる幅は投手の「変化」の値で決まります。COM の投手も、「変化」の高い投手ほど多く変化球を投げ、2 ストライクからはフォークが増えます
- 投げた後の ←→ でも球を少し曲げられます（打者の近くで大きく曲がります。変化球にも足せます）
- 投げた後の ↓ でフォーク、↑ でチェンジアップ（ゆっくりになる）
- 捕手は捕った球を山なりに投手へ返します（影がまっすぐ投手の足元へ進みます）
- ストライクは、ボールがホームベースに 1 ドットでもかかったときだけ。3 つめのストライクは「ストライク」を出してから 1 秒後に「アウト」
- 投手は投げるたびに疲れます（右上の ST）。疲れると最高・最低の球速がどちらも下がります

### 攻め（打者）

- 十字キー：バッターボックスの中で動く（足はボックスの中か線の上まで。ボックスは幅 16 ドット）。バットの芯で打つとライナー、先だとフライ、根っこだとゴロになりやすい
- A：スイング（7 コマのなめらかな振り）。バットが前に出てから当たるほど引っぱり、振り遅れると流し打ち
- 当たった瞬間に止まらず、そのまま打球が飛びます
- 打球・送球・守備・走者の速さは、投球の速さと同じ物差しにそろえてあります（打球の速さ ≒ 投球の速さ。飛ぶ距離と形は実際の物理どおり、
  重力も同じ割合）。ボールの絵は、計算の合間の時刻に合わせて描くので、どのフレームも同じだけ進んで見えます
- 当たる瞬間に押しているキーで打球が変わります（バットの角度の影響のほうが大きい）
  - ↓：打ち上げる（ほとんどがフライになり、高く上がる）　↑：たたきつける（ライナー・ゴロが多くなる）
  - 速い球に非力な打者は押されます（打球が弱くなり、↓ だとポップフライになりやすい）。遅い球を強打者が打つと強い打球に
  - →：右方向へ　←：左方向へ
- **B（押している間）：バントの構え**（人が打つときだけ。キーボードは B / X / M キー、ジョイパッドは B ボタン）。
  バットを両手で持って胸の高さで水平に出します。離すとバットを引きます（引けば見のがしと同じ判定）。当たる瞬間の ←→ で三塁側・一塁側へ転がせます。
  2 ストライクからのバントのファウルは三振です

### 走塁

- B：全員が次の塁へ　／　B ＋ 方向：その塁を目指す走者だけ（→一塁 ↑二塁 ←三塁 ↓本塁）
- A：全員が前の塁へ戻る　／　A ＋ 方向：その走者だけ
- 盗塁：投球中に B ＋ 目指す塁の方向（↑ 一塁の走者が二塁へ、← 二塁の走者が三塁へ）。方向なしの B はバントの構え。
  **盗塁中も B ＋ 元の塁の方向（一塁の走者なら →、二塁の走者なら ↑）で戻り、また B ＋ 次の塁の方向で進み直せます**（何度でも）。
  プレーが始まってからも、B ＋ 元の塁の方向でその走者が戻ります
- **タッチアップ**：フライが捕られると、塁を離れていた走者は元の塁へ戻ります（捕る前に離れた走者は、戻る前に元の塁へ送球されるとアウト）。
  捕った瞬間に塁に触れていた走者、戻って塁を踏み直した走者は、そこから次の塁へ走れます（B）。
  フライが上がった間は、押し出された走者も A で戻れます。COM の走者は、2 アウトまでは外野フライなら二・三塁の走者は塁に戻って
  タッチアップに備え、一塁の走者はハーフウェイ（塁間の 4 割）、内野フライは塁の近く（2 割）で待ちます。捕られた後、送球より先に着けそうなら
  次の塁へ走ります（文字は出しません。フライを捕った外野手は、足を止めてから投げます）。落ちたら走ります
- 塁の上の走者は、いつでも走れるようにリードの構え（低く構えて、すり足）をとります。盗塁はリードの位置から走り出します。
  牽制球が来たら自動で塁へ戻ります（人が走者なら A ですぐ戻れます）
- アウトになった走者はすぐには消えません。一塁へ走っていた打者は、アウトになっても一塁まで走り抜けます
- ホームランの一周は自動で走ります。A か B を押している間は 3 倍の速さになり、演出を早く終えられます
- COM の走者：塁から 8 ドット以上離れたところで、元の塁に守備がボールを持って入ったら、戻らずに次の塁へ走ります。
  ボールを持った守備が次の塁にいれば戻り、追いかけられたら、その守備から遠いほうの塁へ逃げます（挟まれたとき）

### 守備

- ボールにいちばん近い選手を動かします。十字キーを離している間は自動で追いかけます
- 内野と外野で守備範囲を分けています。はっきり外野（外野手の定位置のあたり）へ飛んだ打球は、内野手は追わずに外野手に任せます（内野のすぐ後ろはどちらが追ってもかまいません）
- **B（ボールを持っていないとき）：操作する野手を切り替え**。画面に映っている野手の中で、画面の中心に近い順に替わります（替わった野手は少し点滅します）
- 一塁・三塁に走者がいても、一塁手・三塁手は**定位置**で守ります（ベースにはつきません。牽制球のときだけベースへ走って入って受けます）。
  二塁に走者がいると、遊撃手が二塁ベースの三塁寄りの後ろ（フェアグラウンドの中、リードした走者と重ならない位置）に近づきます。
  打球の処理でベースに入るときは、一塁・三塁はベースのフェア側に入ります
- **ベースカバー**：その塁に入るはずの野手が打球を追っているときは、その塁にいちばん近い手の空いた内野手（投手・捕手を含む）が入ります
  （例：一塁手が追えば投手か二塁手が一塁へ、三塁手が追えば遊撃手が三塁へ、捕手が追えば投手が本塁へ）
- 捕ったら A ＋ 方向で送球（↑二塁 →一塁 ←三塁 ↓本塁、方向なしは一塁）
- **捕球の判定は見た目どおり**：フライ・ライナーは、ボールの絵が野手の体（足元〜頭、横 7 ドット）に重なり、奥行きも近いときだけ捕れます。
  野手はボールが胸の高さ（8 ドット）まで下りてくる所で構えます。一度でもフェアグラウンドで弾めば（弾む音が鳴れば）フライアウトにはなりません。
  送球はグラブに 6 ドットまで届いてから捕ります
- **アウト・セーフの判定**：塁まで残り 4.5 ドット未満の走者は足が塁にかかっているので、封殺もタッチもされません（セーフ）
- B ＋ 方向で、ボールを持ったままその塁へ走ります（ベースを踏めばフォースアウト、走者に触ればタッチアウト）
- **COM の挟殺（ランダウンプレー）**：実際の野球の定石どおりに走者を挟みます。
  1. **フォースプレーが先**：押し出された走者（打者走者など）がまだ走っている間は、ふつうに一塁などへ投げてアウトを取ります
  2. 走者が向かう塁へ、送球のほうが早ければ先回りして送球
  3. 塁と塁の間で止まった・戻りはじめた走者（盗塁中に戻った走者も）には、ボールを持った守備が距離を見て向かっていき
     （64 ドット以内か、走者が塁に着くより先に追いつけるとき）、重なってタッチします。逃げる走者は**元の塁のほうへ追い返します**
     （逃げられても先の塁を与えないため）
  4. 走者が反対側の塁（味方が入っている）の近く（約 3 人分）まで来たら、そこへ投げます。受けた味方が走者に向かってタッチ
  5. 投げた守備は自分の塁へ戻るので、何度往復しても両側から詰まります。戻る走者より送球が早ければ、離れていても元の塁へ投げます

### 画面の表示

打席の画面では、表示を四隅に必要な大きさだけ詰めて出します。

| 場所 | 内容（例） |
|---|---|
| 左上 | 両チームの略称と得点（`DOL 0` / `STA 3`）、回（`1回表` / `1回裏`） |
| 右上 | 投手名、球速（`145km`）、スタミナ（`ST99`） |
| 左下 | いつも 7 文字幅：打順と打者名（`1ヤマダ`）、打率と本塁打（`.291H 3`、`.123H12`） |
| 右下 | ボール・ストライク・アウトのランプ（`B●●●` / `S●●` / `O●●`） |

「ストライク」「ボール」「アウト」「セーフ」「ファウル」「チェンジ」「ツーベース」「スリーベース」「ホームラン」などは画面の真ん中に出ます。

イニングが終わると、プロ野球の球場のバックスクリーンの電光スコアボード（各回の得点・R・H）が出ます。
まわりは夜空・照明塔・時計・両チームの旗・屋根つきのスタンド・バックスクリーン・外野フェンスの広告です。

### 球場と審判

- 審判は 4 人（球審・一塁・二塁・三塁）。ストライク・アウトはこぶしを上げ、セーフは両手を広げ、ファウルは両手を上げます。
  ボールや選手には当たらず、止まりかけたボールが近くに来るとよけます
- 一塁・三塁の後ろのファウルゾーンには屋根つきのベンチがあります。ベンチの前の斜めの壁は、ダイヤモンドの縦の中心で左右対称です。壁に当たったボールはファウル（フェアと決まる前）
- ホームランでは、外野フェンスだけでなく、ファウルゾーンの壁の線（ベンチの前も）とバックネットがすべて黄色に点滅します
- 点が入ると、次の投球が始まるまで、観客が 0.3 秒ごとに跳びはねて手を上げます（2 つの形を交互に）
- ファウルの打球も 2 バウンドまで転がって見えます。ファウルラインの近くで止まったボールは灰色と白で点滅します
- 歓声（約 3 秒の「ワーッ」）：外野へのヒット（フェアの打球が外野で弾んだ瞬間）、点が入った瞬間、ホームランの瞬間に上がります。曲は止まりません
- フライの軌道音：打球が上がっている間「ぴ〜〜」と鳴り、高く上がるほど高い音、落ちてくると低い音になります
- ボールが弾むたびに、必ず弾む音が鳴ります（2 回目までは低い音が 0.1 秒、3 回目からは小さく短い音）
- **痛烈なゴロ**：芯の近くでとらえた強いゴロのうち、ときどき（パワーのある打者ほど多く）何度も弾みながら速く転がる打球になります。
  内野を抜けると外野の壁まで届くことがあります（デモ試合で 5 試合に 1 本ほど）

### 代打・リリーフ

打席の始まり（投手が投げる前）に SELECT を押すと、攻撃側は代打、守備側はリリーフを選べます。

## EDIT モード

タイトルで `EDIT` を選ぶと、チームの一覧が出ます（↑↓ で選んで A。B か START でタイトルへ）。ディスクドライブがないと「ディスク ドライブ ガ アリマセン」と出て戻ります。

チームの画面では、十字キーでカーソル（▶）を動かし、A で書きかえます。START でフロッピーディスクに保存して一覧へ戻ります。

| 行 | 書きかえられるもの |
|---|---|
| いちばん上 | 略称（3 文字）、チーム名（6 文字） |
| 打者 12 人 | 名前（5 文字）、打率（.100〜.355）、パワー（1〜9）、走力（1〜9）。上の 8 人がスタメン（打順どおり）、下の 4 人が控え |
| 投手 5 人 | 名前（5 文字）、最高球速（100〜165km）、最低球速（70km〜最高球速）、変化（1〜9）、スタミナ（1〜9）。いちばん上が先発 |

- 数：↑↓ で 1 ずつ、←→ で 10 ずつ変わります。A か B で決定
- 名前：字の表から十字キーで選んで A で入れる、B で 1 文字消す、START で終わり。
  使える字は、英大文字・数字・`.`・`-`・空白と、カタカナ 71 字（ゥ ェ ォ ゼ ゾ ヂ ヅ ヌ プ ヲ はフォントの空きがないので使えません）
- 打順・控えの入れかえ：B を 2 つの行で押すと、その 2 人が入れかわります（打者どうし・投手どうし）。
  スタメンと控えを入れかえれば、控えの選手をスタメンにできます。投手を入れかえれば先発が変わります
- 保存したチームは、1P VS COM などのふつうの試合・トーナメントでも使われます

## トーナメント

タイトルで `TOURNAMENT` を選ぶと始まります（タイトルの `イニング` がトーナメントの全試合のイニング数になります）。

1. **6 チームを選ぶ**：全 8 球団から ↑↓ と A で 6 つに ● を付けて START
2. **組み合わせ**：画面いっぱいにトーナメント表が出ます。いちばん上といちばん下の 2 チームが**シード**（2 回戦から）。
   A を 2 か所で押すとチームが入れかわります（組み合わせを自由に決められます）。B で 1P のチームを決めます（もう一度押すと「1P なし」）。START で開始
3. 1P のチームの試合は 1P VS COM で遊びます。COM 同士の試合は結果だけ決まります（チームの打率・パワー・投手の力で）。
   1P のチームを「なし」にすると、全試合を COM VS COM で観戦します
4. 勝ったほうの線が黄色になり、点数が表に書かれます。引き分けは安打の多いほう、それも同じならくじ。決勝に勝つと「ユウショウ」

試合の組み合わせ・結果は、**1 試合終わるごとにフロッピーディスクに保存**します（ドライブがないときは保存しません）。
トーナメントの画面（チーム選び・組み合わせ・トーナメント表）で **ESC** を押すと、タイトルへ戻ります（始めた後なら、そこまでの結果は保存済みで、
CONTINUE で続きから再開できます）。

### 続きから（CONTINUE）

タイトルで `CONTINUE` を選ぶと、保存したトーナメントの続き（次の試合）から始まります。
1 試合終わるごとにまた保存されます。トーナメントが終わっていると「セーブ ガ アリマセン」と出ます。

## チーム

DOL ドルフィンズ／FAL ファルコンズ／THU サンダース／COM コメッツ／WOL ウルブズ／ROC ロケッツ／SHA シャークス／STA スターズ（強打の特別チーム）

## 作り直し方（開発者向け）

```
python build.py        # → MSXSTADIUM.ROM
python test/stats.py   # openMSX でデモ試合を回して成績を集計
```

- `tools/`：絵（球場・フォント・スプライト・スコアボードの背景）、曲、チームを作る Python
- `src/`：C（SDCC 4.2）とアセンブラ。`boot/boot.asm`（sjasmplus）が起動部
- 仕組み：起動時にプログラムを RAM（4000h〜EFFFh）へ写して実行し、絵・曲・球場の地図はバンク 4〜 から読みます。
  チーム選択・スコアボードなどの画面はオーバーレイ A（バンク 7 → DD00h〜）、タイトルとトーナメントはオーバーレイ B（バンク 8）、
  EDIT とイニングの間のスコアボードはオーバーレイ C（バンク 9）として、使うときだけ読み込みます。
  オーバーレイ A の後ろ（F000h〜F1FFh）は球場マップに上書きされないので、試合中の関数（牽制など、play2.c）を置いています
- 本体は SDCC の `--max-allocs-per-node 200000` でコンパイルします（コードが小さくなる。1 ファイル数分かかるので、
  ソース・ヘッダ・オプションが同じファイルは `build/obj/*.rel.hash` を見てコンパイルし直しません）
- 保存の中身（MSXSTAD.DAT、1536 バイト）：0 に `MSXS` と版、8 から 8 チーム（各 183 バイト）、その後ろにトーナメントの状態（32 バイト）。
  中身がない（印がちがう）ときは ROM のチームを写します。カートリッジの SRAM には対応していません
- フロッピーディスク：起動部（boot.asm）は、ほかのスロットにまだ初期化されていないディスク ROM があれば H.STKE（全 ROM の初期化の後に呼ばれる）
  につないで BIOS に戻り、ディスク ROM の作業領域ができてから始めます（ディスク ROM がない・もう初期化済みなら、すぐ始める。内蔵ソフトのある機種でも動く）。
  始めるときに `MSXSTAD.DAT` を読んで VRAM 7000h〜 に置き（保存の中身。rom2ram のバンク 10h・ram2sram が VRAM を読み書きする）、ディスクの作業領域
  （HIMEM〜F37Fh）を VRAM 8400h〜 に写します。保存のときは、保存のプログラムを C000h に写し、ゲームの中身（D000h〜F37Fh）を VRAM C400h〜 へ
  退避してディスクの作業領域を戻し、BDOS（F37Dh）でファイルを書いてから入れかえ直します（ゲームの VRAM は 0000h-6FFFh だけ）。
  ディスクエラーは DISKVE のフックで 3 回までやり直させ、4 回目は BDOS の途中から抜けて失敗にします。途中で抜けた後の
  ディスクの作業領域は壊れていることがあるので、VRAM に写すのは成功したときだけです（起動時は読む前の手つかずの作業領域を写す）
  画面は SCREEN 4（G3）。縦は R#23、横は R#18 と名前表 2 枚の切り替えでスクロールします
- 打球を追う場面は、計算（ボール・守備・走者）を 1/30 秒ごと、スクロールとスプライトの表示を 1/60 秒ごとに分けて、
  処理落ちでスクロールがカクつかないようにしています。1 ラインに 9 個以上並ぶときは、点滅させずに重ねの少ない絵へ切り替えます
