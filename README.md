## ブラウザーですぐ遊ぶ（WebMSX）

[**▶ WebMSX で MSX STADIUM を遊ぶ**](https://webmsx.org/?MACHINE=MSX2PJ&ROM_FORMAT=ASCII16&ROM=https://raw.githubusercontent.com/1re1/Baseball/main/msx2/MSXSTADIUM.ROM&DISK=https://raw.githubusercontent.com/1re1/Baseball/main/msx2/save.dsk)

ROM と保存用の空のディスク（`msx2/save.dsk`）を GitHub から直接読み込みます。保存した中身はブラウザーの中のディスクに入るだけなので、続きを残すときは WebMSX のディスクのメニューからディスクイメージを保存（ダウンロード）し、次はそのファイルを画面にドラッグ＆ドロップしてください。
