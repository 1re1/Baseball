## ブラウザーですぐ遊ぶ（WebMSX）

[**▶ WebMSX（C-BIOS 版）で MSX STADIUM を遊ぶ**](https://webmsx.org/cbios/?MACHINE=MSX2J&ROM_FORMAT=ASCII16&ROM=https://raw.githubusercontent.com/1re1/Baseball/main/msx2/MSXSTADIUM.ROM)

WebMSX の C-BIOS 版（`webmsx.org/cbios/`、フリーの互換 BIOS で動く版）で、ROM を GitHub から直接読み込んで始まります。C-BIOS 版にはディスクドライブがないので、EDIT とトーナメントは保存できません。

保存もしたいときは [**▶ ディスク付きで遊ぶ（MSX2+ 日本版）**](https://webmsx.org/?MACHINE=MSX2PJ&ROM_FORMAT=ASCII16&ROM=https://raw.githubusercontent.com/1re1/Baseball/main/msx2/MSXSTADIUM.ROM&DISK=https://raw.githubusercontent.com/1re1/Baseball/main/msx2/save.dsk)

こちらは ROM と保存用の空のディスク（`msx2/save.dsk`）を読み込みます。保存した中身はブラウザーの中のディスクに入るだけなので、続きを残すときは WebMSX のディスクのメニューからディスクイメージを保存（ダウンロード）し、次はそのファイルを画面にドラッグ＆ドロップしてください。
